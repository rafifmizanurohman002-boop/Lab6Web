    Eksperimen 1 — Tombol hapus satu item To-do List

    Setiap tugas pada Latihan 6 kini memiliki tombol Hapus merah di samping tombol Tandai selesai. Klik untuk menghapus satu item dari daftar.

    Berlaku pada form Mini Project: selain wajib diisi, nama harus terdiri dari minimal 3 karakter sebelum dinyatakan valid.

    Pada Mini Project, pilih salah satu sesi. Teks #sesiTerpilih dan ringkasan akan menampilkan sesi yang dipilih melalui event change.

    Paragraf ini bisa disembunyikan dan ditampilkan kembali hanya dengan mengganti class CSS (classList.toggle("tersembunyi")).

    Eksperimen 5 — Script tanpa defer di <head>

    Diuji pada halaman terpisah: eksperimen5.html. Script di <head> tanpa defer dijalankan sebelum <body> diparsing sehingga getElementById() mengembalikan null dan muncul TypeError di Console. Penjelasan lengkap ada di README.
