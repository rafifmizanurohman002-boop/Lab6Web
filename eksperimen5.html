Judul Eksperimen 5

Percobaan: script tanpa defer di bagian <head>

Hasil Pengamatan

Judul di atas TIDAK berubah, padahal script memberi perintah judul.textContent = "Teks ini seharusnya berhasil diubah".

Buka Inspect → Console: muncul Uncaught TypeError: Cannot set properties of null (setting 'textContent') karena document.getElementById("judulEksperimen5") mengembalikan null — elemen tersebut belum diparsing saat script di <head> berjalan (document.readyState = "loading").

Solusi: beri atribut defer pada <script> (dijalankan setelah HTML selesai diparsing) atau pindahkan script ke bagian akhir <body>. Halaman utama index.html memakai defer, sehingga semua latihan berjalan tanpa error.
